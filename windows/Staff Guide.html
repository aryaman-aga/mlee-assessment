MLEE Assessment · Windows toolkit

Staff guide: install, run and test

One installer sets up everything needed to run the four-task assessment (decision trees, Gaussian mixtures via EM, PCA and ICA) and to rebuild its PDF report. You don't need Python, administrator rights or an internet connection.

1  What gets installed

ComponentDetails
Python 3.13A private copy with NumPy, SciPy, scikit-learn, Matplotlib, seaborn, pandas and PyMuPDF. It is used only by this toolkit and leaves any other Python on the PC untouched.
The assessmentThe analysis script, the report source, and the Wine Quality and Old Faithful datasets. The breast-cancer data ships inside scikit-learn.
PDF engineTectonic (a TeX engine) with an offline cache of every TeX file the report needs.
ShortcutsA MLEE Assessment Start-menu folder, a desktop icon, and an entry in Settings → Apps for uninstalling.

Default location: %LOCALAPPDATA%\Programs\MLEE Assessment (per user). The installed size is roughly 0.6 GB.

2  Install

  1. Copy MLEE_Assessment_Setup.exe to the laptop and double-click it.
  2. If Windows shows “Windows protected your PC”, click More info → Run anyway. The installer is not code-signed, so SmartScreen warns about any unsigned download.
  3. Keep the suggested folder, click Install, then Finish. You can open the test console straight from the last page.
Optional integrity check. In a command prompt, run the line below and compare the result with the value in MLEE_Assessment_Setup.exe.sha256: 
certutil -hashfile MLEE_Assessment_Setup.exe SHA256

3  Run

Open Start → MLEE Assessment:

ShortcutWhat it does
MLEE Assessment (test console)A numbered menu: run the analysis, build the PDF, set the student name and ID, open outputs and show the headline results. The desktop icon opens this too.
Run analysisRuns all four tasks (under a minute), compares every number with the reference run, then opens the figures folder.
Build report PDFRuns the analysis, typesets the 5-page report and runs 13 automatic checks (one to two minutes), then opens the PDF.
MLEE command promptA command window with the bundled Python on the path, for running scripts by hand, e.g. python mlee_assessment.py.

The first run takes longer while Windows and Python warm their caches.

4  What a successful test looks like

  • [mlee] results match the reference run: 199 values … means the numbers are identical to the run the report was produced from.
  • QA passed: 5 pages means the PDF met the 6-page limit and passed the font, numeric-consistency and sentence-count checks.
OutputLocation (inside the install folder)
Report PDFapp\output\MLEE_Assessment_Report.pdf
Figures (8)app\report\figures\
All numbersapp\results.json
Logsapp\build\analysis.log and app\build\main.log

5  Common tasks

  • Put a student's name and ID on the report: in the test console, choose 4, type both, then choose 3 to rebuild the PDF.
  • Experiment with the code: edit app\mlee_assessment.py (for example the SEED value) and run it again. The reference comparison will then list the numbers that changed; this is expected.
  • Get back to the original: run the installer again. It replaces the program files but keeps the name and ID you entered.

6  Troubleshooting

SymptomFix
SmartScreen blocks the installerClick More info → Run anyway. If company policy blocks unsigned programs, ask IT to allow the file (its SHA-256 is in the .sha256 file).
Antivirus quarantines a fileRestore it and allow the install folder, then run the installer again.
“Analysis failed”The last lines are printed on screen; the full log is in app\build\analysis.log.
“PDF build failed”See app\build\main.log. The PDF normally builds offline. If a TeX file is missing from the cache, the toolkit downloads it, which needs internet once.
Window closes immediatelyUse MLEE command prompt and run python build.py to keep the messages on screen.

7  Uninstall

Settings → Apps → MLEE Assessment → Uninstall, or Start → MLEE Assessment → Uninstall. This removes the program folder, the shortcuts and the Apps entry.

Third-party components and their licences are listed in THIRD_PARTY_NOTICES.txt in the install folder.
