MLEE Assessment - third-party components
========================================

This toolkit bundles the open-source components below, unmodified. Each one
remains under its own licence. Full licence texts ship with each component,
in the locations given.

Runtime
-------
Python 3.13 (python.org embeddable distribution)
    PSF License Agreement - python\LICENSE.txt
Microsoft Visual C++ runtime DLLs (msvcp140*.dll, vcruntime140*.dll, concrt140.dll)
    Microsoft Visual Studio redistributable code, deployed app-locally
    as permitted by the Visual Studio licence terms.
Tectonic 0.17 TeX engine
    MIT License - https://github.com/tectonic-typesetting/tectonic
TeX files in texcache\ (LaTeX, XCharter, Lato, Inconsolata, tcolorbox, ...)
    Taken from the TeX Live distribution under their own free licences
    (mostly LPPL, SIL OFL and GPL); notices are inside the files.
